About TicketAI

An AI-powered customer support ticket classification system built for MCA 3rd Semester Mini Project.

Step-by-step pipeline
1
📝
Input Text
User enters a support ticket in natural language
→
2

→
3
📐
TF-IDF Scoring
Each token gets a weight based on frequency and importance
→
4
🤖
Naive Bayes
Probabilistic classifier predicts the most likely category
→
5
✅
Result
Category, confidence score, priority and response time shown
